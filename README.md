# Old Script Prox Installer

Branch ini sengaja dibuat untuk menyimpan script old jika masih ingin digunakan



```
git clone -b old-version https://github.com/ryanachmad12/cloud-init-prox-script
```

```
cd cloud-init-prox-script && bash installer.sh
```

Jalan dengan menggunakan root access agar semua berjalan normal
